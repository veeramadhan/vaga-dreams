# 🌿 Vaga Dreams — Boutique Resort Landing Page

> **Vaga Dreams by Z Square Hospitality** — A luxury hill-station retreat in abcd city, Kerala, India.

Built with **Next.js 14 App Router**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, **GSAP**, and **Razorpay** payment integration.

---

## ✨ Features

- 🌙 **Elite dark luxury theme** — deep black with gold gradients
- 🎞️ **Smooth scroll** via Lenis
- 🎬 **GSAP + Framer Motion** scroll-triggered animations
- 🖼️ **Cloudinary-ready** image optimization (`next-cloudinary`)
- 💳 **Razorpay** payment gateway integration
- 📱 Fully **responsive** — mobile-first design
- ⚡ **Turbopack** for blazing-fast dev builds

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Create a `.env.local` file:

```env
RAZORPAY_KEY_ID=rzp_test_XXXXXXXXXX
RAZORPAY_KEY_SECRET=your_razorpay_secret
NEXT_PUBLIC_RAZORPAY_KEY_ID=rzp_test_XXXXXXXXXX
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=your_cloud_name
```

### 3. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
